# 雲林農田水利圖資

讓雲林在地農民用手機打開地圖，就能看到自家田地附近的灌排渠道（圳路）、農業用地與村里界，作為之後「作物需水估算」的基礎。

- **試辦範圍**：雲林縣崙背鄉、褒忠鄉、麥寮鄉
- **試辦作物**：水稻、花生（需水估算規劃中）
- **目前版本**：v0.2（圖資檢視 + 連線診斷）
- **線上網址**：https://scanhsu.github.io/yunlin-irrigation/ （開啟 GitHub Pages 後生效）

---

## 功能

| 功能 | 說明 |
|---|---|
| 底圖切換 | 國土測繪中心通用電子地圖、正射影像、OSM（測試用） |
| 灌排渠道圖層 | 農田水利署各管理處已公告之灌排渠道 |
| 國土利用圖層 | 農業用地、水利用地（可開關） |
| 村里界 | 方便確認田地所在村里 |
| 點選查詢 | 點地圖任一點，顯示座標並查詢該處圳路資訊 |
| 連線診斷 | 開啟時自動測試各圖資服務是否可連線，結果可一鍵複製 |
| 測試點 | 崙背鄉大有村（Plus Code `P8X3+7VJ`，約 23.7482, 120.3046） |

手機、電腦皆可使用，不需安裝任何程式。

---

## 使用方式

1. 用手機或電腦瀏覽器開啟上方網址。
2. 地圖會自動對準測試點（藍色圓點）。
3. 右上角圖層選單可切換底圖、開關各圖層。
4. 點地圖上任一位置，下方面板會顯示座標與圳路查詢結果。
   - 若顯示「在新分頁查看圳路資訊」，點連結即可另開查看。
5. 若地圖空白，請看面板中的「連線診斷」，按「複製診斷結果」回報問題。

> ⚠️ 請用一般瀏覽器（Chrome、Edge、Safari）開啟。在部分 App 的內嵌預覽視窗中，外部地圖圖片可能會被擋，導致地圖空白。

## 資料來源

| 圖層 | 提供單位 | 服務 | 資料日期 |
|---|---|---|---|
| 灌排渠道 | 農業部農田水利署 | WMS `canal_public`<br>`https://www.iacloud.ia.gov.tw/servergate/sgsgate.ashx/WMS/canal_public` | 2017-05-01 |
| 通用電子地圖、正射影像 | 內政部國土測繪中心 | WMTS `https://wmts.nlsc.gov.tw/wmts` | 依服務更新 |
| 國土利用現況、村里界 | 內政部國土測繪中心 | WMS `https://wms.nlsc.gov.tw/wms` | 依服務更新 |
| OSM 底圖（測試用） | OpenStreetMap 貢獻者 | `tile.openstreetmap.org` | 即時 |

- 政府圖資依各資料集公告之授權條款使用（多為「政府資料開放授權條款」），使用前請至各資料集頁面確認。
- OSM 圖磚僅供開發測試，正式上線將改用自架底圖，以符合 [OSM 圖磚使用政策](https://operations.osmfoundation.org/policies/tiles/)。
- 灌排渠道資料為 2017 年版本，與現況可能有出入；僅含已公告之幹線、支線與主要排水，不含田間小給水路。

## 已知限制

- 所有圖層皆為「圖片」（WMS/WMTS），只能檢視，尚無法做「離我最近的圳路」等空間查詢。
- 點選查詢依賴農田水利署服務；若瀏覽器跨網域限制，會改以連結另開。
- 圖資服務由政府單位提供，服務中斷時圖層會無法顯示。

## 檔案結構

```
yunlin-irrigation/
├── index.html   # 整個網頁（地圖、圖層、診斷、點選查詢），單一檔案
└── README.md    # 本說明文件
```

使用 [Leaflet 1.9.4](https://leafletjs.com/)（由 cdnjs 載入），無需建置或安裝套件。

---

## 本機測試

1. 下載 `index.html` 到電腦。
2. 對檔案按右鍵 →「開啟檔案」→ 選 Chrome 或 Edge。
3. 等待約 10 秒，查看左下角「連線診斷」結果。

---

## 部署（GitHub Pages）

1. 將 `index.html` 與 `README.md` 放在 repo 根目錄。
2. 進入 repo 的 **Settings → Pages**。
3. 「Source」選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 **Save**。
4. 約 1–2 分鐘後，網址 `https://scanhsu.github.io/yunlin-irrigation/` 即生效。
5. 之後每次推送更新到 `main`，網站會自動更新。
